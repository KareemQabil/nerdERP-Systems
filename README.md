# nerdERP-Systems

Public ERP systems reference focused on modular architecture, POS workflows, inventory flows, and business-software design.

This repository acts as a systems-oriented companion to the broader NerdERP work. The emphasis here is on modules, workflow boundaries, and implementation structure for ERP/POS software.

## Focus areas

- Modular backend and frontend structure
- POS and order management flows
- Inventory and purchasing workflows
- Reporting and operations dashboards
- Arabic-first interfaces and RTL support

## Public note

This repository is public to demonstrate system thinking, architecture direction, and product scope. Production repositories and client-specific deployments remain private when they contain proprietary business logic or operational data.

## Status

- Public architecture and reference repository
- Useful for understanding product direction and module design
- Not positioned as a verified production deployment or compliance artifact

## Tech direction

- Frontend: React, TypeScript, Vite
- Backend: NestJS, TypeScript, PostgreSQL
- Product areas: POS, inventory, reporting, admin tools

## Notes

Public-facing documentation for the broader ERP/POS stack will continue to move toward sanitized case studies rather than direct exposure of private business code.
